# Wizard de configuração (rascunho)

Os nomes de telas podem mudar. Validar com a documentação oficial da Meta antes de publicar.

1. **Conta Meta Business:** entre no Meta Business Manager e crie ou use uma conta existente.
2. **App de desenvolvedor:** em developers.facebook.com, crie um app do tipo Business e adicione o produto WhatsApp.
3. **Número:** adicione o número de telefone. Recomendamos um número dedicado, mas qualquer número serve. Confirme por SMS ou ligação.
4. **Credenciais:** copie o ID do número e gere um token de acesso. Os dados são informados no nosso sistema, nunca no chat.
5. **Templates:** crie os modelos de mensagem do relatório e aguarde a aprovação da Meta.
6. **Webhook:** configure o endereço de retorno fornecido pelo nosso sistema.
7. **Teste:** envio de teste somente com aprovação e para o número indicado pelo usuário.

Pendência: confirmar se a Cloud API envia template para grupos. Se não enviar, definir o desenho com a Evolution.
