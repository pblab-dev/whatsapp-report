# Decisões de produto

- **Base de leitura de grupos:** Evolution API (sessão WhatsApp Web). Pendente confirmar desenho com a Cloud API para envio.
- **Setup:** após o usuário conectar o WhatsApp na Evolution, o sistema lista os grupos ativos da conta e o usuário escolhe quais monitorar.
- **Destinatários:** o usuário escolhe um grupo-alvo, um usuário ou vários, durante o setup.
- **Periodicidade:** o usuário escolhe. Sugestões: 2x ao dia (08:00 e 20:00) ou 1x à noite (22:00), fuso America/Fortaleza.
- **Formato:** texto normal no WhatsApp, ou API para Power BI ou banco, se o usuário fornecer.
- **Formato do texto:** título com emoji de tema → linha 📍 contexto → veredito na primeira tela → tabelas por origem → 🎯 diagnóstico → 🔗 impacto → ⚠️ limitações e sinalizações com emojis.
- **Número:** recomendar número dedicado, sem obrigar.
- **Riscos:** não falar de banimento no setup do usuário (já consta na página oficial). O alerta continua para o dono.
- **Setup ideal:** Meta Cloud API com templates prontos.
- **Produto:** próprio, com as funcionalidades equivalentes ao concorrente.
- **Autorização:** criar integrações, instâncias, rotinas, grupos ou alterar instruções exige aprovação explícita do dono.
